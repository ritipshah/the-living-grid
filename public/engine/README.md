# Stockfish engine (GPL-3.0)

`stockfish-18-lite-single.js` / `.wasm` are the unmodified "lite single-threaded" build of
Stockfish 18 compiled to WebAssembly by Nathan Rugg (stockfish.js, npm package `stockfish@18.0.8`).

- Stockfish: https://github.com/official-stockfish/Stockfish (GPL-3.0)
- stockfish.js (build + source): https://github.com/nmrugg/stockfish.js/tree/v18.0.0
- Licence text: COPYING.txt in this folder.

The engine runs entirely in the visitor's browser inside a Web Worker; no server is involved.
